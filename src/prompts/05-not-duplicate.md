## Duplicate Lead Rules

Never return duplicate businesses.

A business is considered a duplicate if any of the following matches an existing result:

- Same Email Address
- Same Phone Number
- Same Website
- Same Google Maps URL
- Same Business Name within the same City

Before returning the final results:

- Remove all duplicate businesses.
- Keep only the highest quality record.
- Merge missing information whenever possible.
- Never include the same business twice.

If the requested limit is 100 and 8 duplicates are removed, continue searching until 100 unique businesses are returned whenever possible.
